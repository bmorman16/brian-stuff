## Principal agent problems

Acency problems come when principal and agent have differing incentives.  
A real estate agent is the 'agent' to you the home owner as 'principal'.  
A problem of this kind would be an agent going out of their way to make more money rather than find you the best fit house.  
The agent is then given a stake in the principals objective - like stock options - in order to prevent principal agent problems.  
    
### Behavioral issues of Principal agent
Empire building - CEO's look to gather strength.  
Egocentric Bias - considering yourself to be the only factor of success.  
Groupthink - suppressing dissenting viewpoints.
